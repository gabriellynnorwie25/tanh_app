# Tanh Activation Function

## 1. Project Overview

This project is a web application developed to visualise the Hyperbolic Tangent (Tanh) activation function used in neural networks. The application is developed using Python and Streamlit.

Users can change the input value using an interactive slider. The application automatically calculates the output and displays the Tanh graph.

## 2. Activation Function

Tanh is an activation function that converts input values into outputs between -1 and 1.

**Formula:**

f(x) = tanh(x)

## 3. Technologies Used

- Python
- Streamlit
- NumPy
- Matplotlib
- Visual Studio Code

## 4. Application Features

- Interactive slider to select an input value.
- Automatic calculation of the Tanh output.
- Graphical visualisation of the Tanh function.
- Explanation of how the function works.

## 5. Installation

Install the required libraries using:

```bash
pip install streamlit numpy matplotlib
```

## 6. How to Run

Run the following command in the VS Code terminal:

```bash
streamlit run tanh_app.py
```

The application will open in your web browser.
